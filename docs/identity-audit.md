# Identity and compatibility audit

The maintained project is **Instagram-CLI**, at **rugbedbugg/Instagram-CLI**, with private npm identity **insta-cli**. This audit records the deliberate exceptions to renaming, rather than treating every old-name substring as a stale brand.

## Classification used for the rebrand

| Class                          | Decision                                                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| Project/repository identity    | Use Instagram-CLI and canonical downstream links for current documentation, GitHub metadata, issue links, and package metadata. |
| TypeScript npm identity        | Use `insta-cli` in the manifest and both lockfile root names; keep `private: true` and version `2.0.1`.                         |
| Executable name                | Use `insta-cli` in current examples and help. Keep `instagram-cli` as an alias to the same entry point.                         |
| Persistent paths               | Keep `.instagram-cli`, config/session filenames, and `INSTAGRAM_CLI_HOME`; do not migrate stored state.                         |
| Historical/upstream references | Keep original ancestry, copyright, upstream release identifiers, and explicitly labeled legacy packaging.                       |
| Protocol/API identifiers       | Preserve API constants, user-agent/fingerprint values, dependency names, and wire fields.                                       |
| Source/module names            | Preserve internal hooks, Python imports, safety categories, and temporary test prefixes.                                        |
